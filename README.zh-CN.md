## 快速开始

### 1. 在电脑上安装

推荐从桌面应用开始：它会帮你配置好 CLI 和守护进程。

<details>
<summary><b>更喜欢用终端？</b>不装桌面应用，直接安装 CLI 和守护进程</summary>

macOS/Linux：

```bash
curl -fsSL https://happier.dev/install | bash
```

Windows：

```powershell
iwr https://happier.dev/install.ps1 -useb | iex
```

如果你确实想用 npm 包：`npm install -g @happier-dev/cli`（[CLI 文档](https://docs.happier.dev/apps/cli)）。

</details>

<details>
<summary><b>要装在远程电脑或 devbox 上？</b>在本机通过 SSH 完成配置</summary>

一条命令即可在远程主机上安装 CLI 和守护进程（已验证发布签名），并将其注册为你的一台机器：

```bash
happier machine setup --ssh user@host
```

如果远程机器上没有浏览器，可以在一台已登录的机器上运行以下命令，让远程机器完成登录：

```bash
happier auth pair-remote --ssh user@host
```

也可以直接在远程主机上以无头方式登录：`happier auth login --no-open --method web` 会输出一个授权 URL，在任意浏览器中批准即可。[机器与守护进程](https://docs.happier.dev/apps/daemon)

</details>

在应用中登录，或在首次运行时登录。

### 3. 开始会话

**在应用中 →** 点击 **新会话**，选择机器、文件夹和代理。无需终端。

**或者在终端中**，在任意项目文件夹下运行：

```bash
happier            # Claude Code
happier codex      # Codex
happier opencode   # OpenCode
```

无论哪种方式，会话都会同时出现在所有设备上：在终端里继续输入，在手机上跟进并审批，在浏览器里审查。运行 `happier --help` 可查看其他代理和命令。

### 更多功能

- **会话移交。** 把正在运行的 Claude Code 或 OpenCode 会话转移到另一台机器，需要的话可以连同工作树一起带过去。[会话移交](https://docs.happier.dev/sessions/session-handoff)
- **会话共享。** 邀请他人以查看或编辑权限加入，或发布一个只读的公开链接。[会话共享](https://docs.happier.dev/accounts/session-sharing)
- **把 Happier 用作 MCP 服务器。** `happier mcp serve` 让任意 MCP 宿主都能创建会话、发送消息和执行会话操作。[把 Happier 用作 MCP 服务器](https://docs.happier.dev/extending/happier-as-mcp-server) · [CLI](https://docs.happier.dev/apps/cli)
- **MCP 服务器只需配置一次。** 每台机器上的每个代理都能使用。[MCP 服务器](https://docs.happier.dev/extending/mcp-servers)
- **通过 SSH 添加机器**，在应用或 CLI 中都可以操作。[机器与守护进程](https://docs.happier.dev/apps/daemon)
- **自托管。** 自托管的中继运行相同的应用、加密和功能。[自托管](https://docs.happier.dev/self-hosting)
- **端到端加密。** 内容默认在你的设备上加密。[安全](#security)

分步指南请见 [guides.happier.dev](https://guides.happier.dev)。

## Happier 的工作原理

```
      Phone           Desktop          Browser
        │                │                │
        └────────────────┼────────────────┘
                         │
                         ▼
          Happier relay (hosted or yours)
        syncs end-to-end encrypted sessions
          between your devices and machines
                         │
                         ▼
      Your machines (laptop, desktop, VPS, dev box)
        the Happier daemon starts and manages
          agent processes where your code lives
                         │
                         ▼
      Claude Code · Codex · OpenCode · Pi · ...
        each agent talks to its own model
                provider directly
```

中继负责存储和转发它自己无法读取的内容：会话内容在到达服务器之前就已在你的设备上加密。服务器只处理路由所需的信息，例如会话 ID、时间戳、轮次状态和用量元数据。你的代理仍然直接与各自的模型提供商通信。

<a id="self-hosting"></a>
## 自托管

一条命令即可运行你自己的中继：

```bash
happier relay host install --mode system
```

这会在当前机器上安装一个托管的中继服务并负责更新。如果是远程主机：`happier relay host install --ssh user@host --mode system`。

详细内容见[自托管文档](https://docs.happier.dev/self-hosting/self-host-runtime)（也可以通过 [happier.dev/self-host](https://happier.dev/self-host) 访问），另外也可以选择 [Docker](https://docs.happier.dev/self-hosting/docker) 或 [Proxmox](https://docs.happier.dev/self-hosting/proxmox)。

<a id="security"></a>
## 安全

- **内容默认端到端加密。** 代码、提示词、消息和对话记录在到达任何服务器之前就已在你的设备上加密。[加密](https://docs.happier.dev/security/encryption)
- **服务器会处理路由元数据。** 会话 ID、时间戳、轮次状态和用量元数据对中继可见，以便同步你的设备。
- **自托管运营者可以自行选择存储策略。** 自托管服务器可以根据自身部署配置其他存储策略。[服务器加密设置](https://docs.happier.dev/self-hosting/encryption)
- **模型流量只经过你的代理。** 每个代理直接与各自的模型提供商通信。

更多内容见[安全文档](https://docs.happier.dev/security)。

### 发布渠道和每夜构建

以上方式安装的都是 **stable** 渠道。另有两个更新更快的渠道领先于它，并且可以并行安装（`happier`、`hprev`、`hdev`），所以试用它们不会影响你的 stable 环境：

- **preview**：新功能会先在这里上线，早于 stable。
- **dev**：包含最新改动的每夜构建。可能包含不完整的提交，随时可能出问题。

<details>
<summary><b>安装 preview 或 dev 构建</b></summary>

Preview（先是 macOS/Linux，然后是 Windows）：

```bash
curl -fsSL https://happier.dev/install-preview | bash
```

```powershell
iwr https://happier.dev/install-preview.ps1 -useb | iex
```

Dev：

```bash
curl -fsSL https://happier.dev/install-dev | bash
```

```powershell
iwr https://happier.dev/install-dev.ps1 -useb | iex
```

之后用 **`hprev`** 或 **`hdev`** 代替 `happier`。如果想让 `happier` 指向 dev 通道，可以在 `.bashrc`/`.zshrc` 中加入 `alias happier='hdev'`。

使用 `dev` 时，所有组件都必须来自 dev 版本（CLI、应用、守护进程和服务器）：托管云服务（cloud.happier.dev）运行的是 `stable`，因此 `preview` 和 `dev` 的功能在上面可能无法使用；而且 `dev` 没有托管的 Web 应用（要使用 dev 版 Web UI，请自托管 dev 服务器）。

## 为什么叫“Happier”？

我们最初是 [Happy](https://github.com/slopus/happy) 的贡献者，向上游提交修复、改进和新功能。

我们每天都在工作中使用它，也是真心喜欢这个理念。
后来我们逐渐意识到，自己的需求需要更快的迭代，而这在主项目中很难放开手脚去尝试。

于是我们开始为自己构建这些功能。

经过数周的打磨、修复和对基础的扩展，我们决定把 Happier 分享出来，让更多人可以试用、使用，并一起决定它接下来的方向。

Happier 想探索一个迭代更快、协作更多的方向，同时由衷感谢 Happy 打下的基础。我们曾经喜欢、现在也依然喜欢 Happy。❤️ 没有它，就没有 Happier。
