## はじめに

### 1. コンピューターにインストールする

おすすめはデスクトップアプリです。CLI とデーモンを自動でセットアップします。

<a href="https://happier.dev/download">
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset=".github/download-desktop-white.svg" />
    <img width="186" height="45" alt="Happier デスクトップ版をダウンロード: macOS、Windows、Linux" src=".github/download-desktop-white.svg" />
  </picture>
</a>
<br /><br />
<details>
<summary><b>ターミナル派ですか?</b> デスクトップアプリなしで CLI とデーモンをインストール</summary>

macOS/Linux:

```bash
curl -fsSL https://happier.dev/install | bash
```

Windows:

```powershell
iwr https://happier.dev/install.ps1 -useb | iex
```

npm パッケージを使いたい場合は `npm install -g @happier-dev/cli` を実行してください ([CLI ドキュメント](https://docs.happier.dev/apps/cli))。

</details>

<details>
<summary><b>リモートのコンピューターや devbox にインストールしますか?</b> 手元のマシンから SSH 経由でセットアップ</summary>

次のコマンドひとつで、リモートホストに CLI とデーモンをインストールし (リリース署名を検証済み)、あなたのマシンのひとつとして登録します。

```bash
happier machine setup --ssh user@host
```

リモートマシン側でブラウザを使わずにサインインさせるには、すでにサインイン済みのマシンから次を実行します。

```bash
happier auth pair-remote --ssh user@host
```

リモートホスト上で直接ヘッドレスに行う方法もあります: `happier auth login --no-open --method web` を実行すると認証用 URL が表示され、任意のブラウザから承認できます。[マシンとデーモン](https://docs.happier.dev/apps/daemon)

</details>

サインインはアプリから、または初回起動時に行います。

### 3. セッションを開始する

**アプリで →** **新規セッション** を押し、マシン、フォルダ、エージェントを選びます。ターミナルは不要です。

**またはターミナルで**、任意のプロジェクトフォルダから:

```bash
happier            # Claude Code
happier codex      # Codex
happier opencode   # OpenCode
```

どちらの方法でも、セッションはすべてのデバイスに同時に表示されます。ターミナルで入力を続け、スマートフォンで進行を追って承認し、ブラウザでレビューできます。ほかのエージェントやコマンドは `happier --help` で確認できます。

### そのほかの機能

- **セッションの引き継ぎ。** 実行中の Claude Code や OpenCode のセッションを別のマシンへ移せます。必要なら作業ツリーも一緒に移せます。[セッションの引き継ぎ](https://docs.happier.dev/sessions/session-handoff)
- **セッションの共有。** 閲覧または編集の権限を付けて招待したり、読み取り専用の公開リンクを発行したりできます。[セッションの共有](https://docs.happier.dev/accounts/session-sharing)
- **MCP サーバーとしての Happier。** `happier mcp serve` を使うと、任意の MCP ホストからセッションの作成、メッセージの送信、セッション操作の実行ができます。[MCP サーバーとしての Happier](https://docs.happier.dev/extending/happier-as-mcp-server) · [CLI](https://docs.happier.dev/apps/cli)
- **MCP サーバーの設定は一度だけ。** すべてのマシンのすべてのエージェントで使えます。[MCP サーバー](https://docs.happier.dev/extending/mcp-servers)
- **SSH 経由でマシンを追加**。アプリからも CLI からもできます。[マシンとデーモン](https://docs.happier.dev/apps/daemon)
- **セルフホスト。** セルフホストのリレーでも、同じアプリ、暗号化、機能が動きます。[セルフホスト](https://docs.happier.dev/self-hosting)
- **エンドツーエンド暗号化。** コンテンツはデフォルトでデバイス上で暗号化されます。[セキュリティ](#security)

ステップごとのガイドは [guides.happier.dev](https://guides.happier.dev) にあります。

## Happier のしくみ

```
      Phone           Desktop          Browser
        │                │                │
        └────────────────┼────────────────┘
                         │
                         ▼
          Happier relay (hosted or yours)
        syncs end-to-end encrypted sessions
          between your devices and machines
                         │
                         ▼
      Your machines (laptop, desktop, VPS, dev box)
        the Happier daemon starts and manages
          agent processes where your code lives
                         │
                         ▼
      Claude Code · Codex · OpenCode · Pi · ...
        each agent talks to its own model
                provider directly
```

リレーは、自身では読めないコンテンツを保存し、転送します。セッションの内容はサーバーに届く前にデバイス上で暗号化されます。サーバーが処理するのは、セッション ID、タイムスタンプ、ターンの状態、使用量メタデータなど、ルーティングに必要な情報だけです。エージェントはこれまでどおり、それぞれのモデルプロバイダーと直接通信します。

<a id="self-hosting"></a>
## セルフホスト

コマンドひとつで自分のリレーを動かせます。

```bash
happier relay host install --mode system
```

これにより、現在のマシンに管理されたリレーサービスがインストールされ、更新も行われます。リモートホストの場合: `happier relay host install --ssh user@host --mode system`。

詳しくは [セルフホストのドキュメント](https://docs.happier.dev/self-hosting/self-host-runtime) ([happier.dev/self-host](https://happier.dev/self-host) からもアクセス可能) を参照してください。[Docker](https://docs.happier.dev/self-hosting/docker) や [Proxmox](https://docs.happier.dev/self-hosting/proxmox) を使う方法もあります。

<a id="security"></a>
## セキュリティ

- **コンテンツはデフォルトでエンドツーエンド暗号化されます。** コード、プロンプト、メッセージ、トランスクリプトは、サーバーに届く前にデバイス上で暗号化されます。[暗号化](https://docs.happier.dev/security/encryption)
- **サーバーはルーティング用のメタデータを処理します。** デバイス間を同期するため、セッション ID、タイムスタンプ、ターンの状態、使用量メタデータはリレーから参照できます。
- **セルフホストの運用者はストレージポリシーを選べます。** セルフホストのサーバーは、デプロイに合わせて別のストレージポリシーで構成できます。[サーバーの暗号化設定](https://docs.happier.dev/self-hosting/encryption)
- **モデルとの通信はエージェントが直接行います。** 各エージェントはそれぞれのモデルプロバイダーと直接通信します。

詳しくは [セキュリティのドキュメント](https://docs.happier.dev/security) をご覧ください。

### リリースチャンネルとナイトリービルド

上記の方法はすべて **stable** チャンネルをインストールします。それより先行する 2 つのチャンネルがあり、並行してインストールできる (`happier`、`hprev`、`hdev`) ため、試しても stable の環境が壊れることはありません。

- **preview**: 新機能は stable より先にここに入ります。
- **dev**: 最新の変更を含むナイトリービルドです。不完全なコミットを含むことがあり、いつ壊れてもおかしくありません。

<details>
<summary><b>preview または dev ビルドをインストール</b></summary>

Preview (macOS/Linux、次に Windows):

```bash
curl -fsSL https://happier.dev/install-preview | bash
```

```powershell
iwr https://happier.dev/install-preview.ps1 -useb | iex
```

Dev:

```bash
curl -fsSL https://happier.dev/install-dev | bash
```

```powershell
iwr https://happier.dev/install-dev.ps1 -useb | iex
```

その後は `happier` の代わりに **`hprev`** または **`hdev`** を実行します。`happier` を dev レーンに割り当てたい場合は、`.bashrc`/`.zshrc` に `alias happier='hdev'` を追加してください。

`dev` では、すべてを dev リリースで揃える必要があります (CLI、アプリ、デーモン、サーバー)。ホスト型クラウド (cloud.happier.dev) は `stable` で動いているため、`preview` や `dev` の機能はそこでは動かない場合があります。また `dev` にはホスト型の Web アプリがありません (dev の Web UI を使うには dev サーバーをセルフホストしてください)。

## なぜ「Happier」?

私たちはもともと [Happy](https://github.com/slopus/happy) のコントリビューターとして、修正、改善、新機能をアップストリームに送っていました。

仕事で毎日使っていて、そのコンセプトが本当に好きでした。
しかし次第に、自分たちのニーズにはもっと速い開発サイクルが必要で、それをメインのプロジェクトの中で無理なく試すのは難しいと気づきました。

そこで、自分たちのために作り始めました。

何週間もかけて土台を磨き、修正し、拡張したあと、ほかの人にも試して、使って、これからの方向づくりに参加してもらえるよう Happier を公開することにしました。

Happier は、Happy が築いた土台に深く感謝しつつ、より速く、より協働的な方向を探るプロジェクトです。私たちは Happy が大好きでしたし、今も大好きです。❤️ Happy がなければ Happier は存在しませんでした。
