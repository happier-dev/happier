Happier is a sync system for CLI + mobile/web clients with explicit storage modes.
E2EE content remains opaque to the sync server. Plaintext-account and plaintext-Session
content is intentionally server-readable and may optionally be sealed by the server at
rest; that sealing is not end-to-end encryption.

## What lives in this repo

- **Server**: sync API + realtime updates.
- **CLI**: local agent runner + daemon + remote sync client.
- **App**: mobile + web UI for sessions and devices.
- **Protocol**: shared types/contracts between components.
- **Plugins**: manifest-first extension points for actions, hooks, UI, MCP, and AI backends.
- **Website / Docs**: deployable static sites.
