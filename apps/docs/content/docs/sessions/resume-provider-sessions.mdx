Happier can start a **new session** by resuming an **existing Agent session**.

This is useful when you already have a session started outside Happier (for example in a terminal) but you want to continue it from the Happier UI.

This page is about the **Resume ID** flow. It is different from:

- [Resume inactive sessions](/sessions/session-resume) (resuming an existing Happier session)
- [Browse and import Agent sessions](/sessions/browse-and-import-sessions) (opening Agent sessions as direct sessions and optionally syncing them)

## What “Resume ID” means

**Resume ID** is the Agent’s session identifier (or resumable session key) that the backend uses to reopen an existing Agent session.

When you start a session with a Resume ID:

- Happier creates a new Happier session
- the Agent resumes the existing Agent session using that id
- Happier connects to that resumed Agent session

## Where to use it

You can enter a Resume ID in the **new-session** flow:

1. Open the new session screen
2. Choose the Agent (Codex, Claude, OpenCode, …)
3. Open the input controls and find **Resume ID**
4. Paste the Agent session id, or use **Browse** when available

For the broader session-start flow, see [Start a new session](/sessions/start-a-session).

## Browse existing sessions to fill the Resume ID

For some Agents, Happier can browse the Agent’s existing sessions and let you pick one to fill the Resume ID field.

When it is available, you will see a **browse icon** next to the Resume ID input.

The browse experience is designed to stay in the same session-start flow:

- the browser opens as a dedicated in-place picker surface
- it does not mean the current new-session setup was canceled
- choosing an entry fills the Resume ID field and returns you to session start

Important behavior:

- The browse picker is shown only when the selected backend supports session browsing.
- The browse list is scoped to the Agent and machine you already selected in the new-session screen.
- For Codex, the browse list is also scoped to the effective Codex home for the auth choice you selected (see below).
- On smaller screens, the same picker uses a larger touch-friendly modal layout instead of a tiny anchored popover.

When you pick a session, Happier fills the Resume ID field and closes the Resume ID control.

### Codex homes and connected services

Codex can have more than one “home” in Happier:

- the standard user Codex home on the machine
- a connected-service-backed Codex home (when you start Codex with a connected service profile)

The Resume ID browse picker is intentionally **locked** to the Codex home implied by your current new-session selection so you do not accidentally pick a session from a different home that will not resume under the selected auth.

If you want to browse sessions from a different Codex home:

1. change the Codex auth choice in the new-session flow (native vs connected service profile)
2. reopen the Resume ID picker and browse again

## Troubleshooting

If you do not see the browse icon:

- the Agent may not support session browsing in current builds, or
- no machine is selected yet

You can still paste a Resume ID manually.

If the browse list is empty:

- confirm the selected machine is online and reachable, and
- confirm you are browsing the correct Agent/auth context (for Codex, the correct home/profile).
