An agent's claim about what it changed is not the same as the diff. These pages
are about closing that gap from inside Happier, on whatever device you have.

- [Files and the editor](/code/files-and-editor) — browsing, searching and editing the workspace.
- [Diffs and review](/code/diffs) — reading changes by repository, by turn, by session, or by what you have staged.
- [Review comments](/code/review-comments) — marking exact lines and turning those notes into instructions for an agent.
- [Git](/code/git) — staging, committing, branches and stashes, with guardrails on anything that could lose work.
- [Pull requests](/code/pull-requests) — publishing a branch and opening or reusing a request.

Git write operations are gated and off by default; each page states its own
availability.
