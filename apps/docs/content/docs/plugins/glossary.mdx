---
title: Plugin glossary
description: Public terms used by the Happier Plugin SDK.
---

| Term | Meaning |
| --- | --- |
| Plugin | An installable package with a cold manifest and optional executable daemon and client code. The package is the unit of installation and trust. |
| Cold manifest | `.happier-plugin/plugin.json`, parsed without importing plugin code. It declares identity, entrypoints, access requests, and contributions. |
| Contribution | A manifest-declared capability such as an action, hook, Agent, setting, or UI surface. |
| Plugin API | `PluginApi`, passed to the named `activate(api)` function. It registers implementations only for manifest-declared contribution ids. |
| Invocation context | `PluginInvocationContext`, passed when the host invokes a contribution. It contains identity, cancellation, services, and `context.ui`. |
| Agent | An executable coding backend contributed under `contributes.agents`. Agents are not model Providers. |
| Agent runtime | Native `AgentRuntime` registered for an Agent. It supplies session and/or execution-run factories while the host owns shared lifecycle and persistence. |
| Provider | A model source such as OpenRouter, Ollama, or LM Studio. Provider metadata and account-owned Provider connections are separate from Agents. |
| Host access | Required disclosure/cooperative service configuration or optional access to an independently host-owned resource. Ambient local process powers are not sandbox grants. |
| Declarative UI | A host-rendered surface described by public data rather than arbitrary client code. |
| Hosted web UI | Isolated web content that communicates through the public Plugin UI host API. It does not sandbox other code in the package. |
| React Native UI | Trusted package code loaded in a supported client realm. It is the default native-feeling executable UI model, not a sandbox. |
| UI artifact | A build output described by `ui-artifacts.json` and verified by the host before use. |
| Plugin testkit | `createPluginTestkit` from `@happier-dev/plugin-sdk/testing`, used to activate a module and invoke registered contributions in tests. |
| Developer Preview | The stability level of every public `@happier-dev/plugin-sdk` path until 1.0. Patch releases should not intentionally break documented contracts; documented 0.x minors may include breaking changes and migration notes. |
