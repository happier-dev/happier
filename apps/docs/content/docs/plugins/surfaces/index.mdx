---
title: Agent capabilities
description: Optional terminal and external-session capabilities contributed by an Agent plugin.
---

Agent plugins can contribute two adjacent optional capability families:

- `AgentRuntime.surfaces.terminal` resolves an Agent-specific terminal launch
  plan.
- `agents.<id>.externalSessions` supplies the six-method External Sessions
  auxiliary for Agent-native sessions created outside Happier; generated
  activation performs the matching registration.

External Sessions is not an `AgentRuntime.surfaces` field. Both capabilities
use the same manifest-declared Agent identity, while the host owns product
flow, permissions, Happier session records, transcript projection, and
cleanup.

Create, resume, and fork are typed `AgentSessionOpenRequest` variants handled by `sessions.open(...)`; they are not separate runtime registries or author-defined lifecycle owners. Execution-run checkpoints are native execution-run events, not a general workspace restore surface.
