---
title: Terminal surface
description: Resolve an Agent-specific terminal launch plan.
---

Implement `AgentRuntime.surfaces.terminal.resolveLaunch(request)` when the Agent can run in a host terminal.

The result contains the executable argument vector, optional launch environment, supported process presentation, and bounded result metadata. The Agent leaf owns its CLI arguments and native breadcrumbs. The host owns terminal selection, process presentation, liveness, input policy, session continuity, and public state.

Terminal metadata does not grant write access to a running session. Do not write Happier transcript rows or session state directly; return the public launch plan and let the host apply supported result metadata.
