---
title: Checkpoint surface
description: Expose agent or workspace checkpoints for listing and restore.
---

Checkpoint surfaces let an agent runtime expose restore points or snapshots.

## Agent vs workspace ownership

Agent leaves may know native checkpoints. SCM/workspace integrations may know repository snapshots or worktree state. The host owns the product restore flow and permission boundaries.

## Operations

A checkpoint surface can provide:

- checkpoint availability
- checkpoint listing
- restore target resolution
- restore by anchor or target
- typed restore diagnostics

## Safety

Restores can change files or session state. They should require explicit user intent, typed diagnostics, and validation against the current workspace/session.
