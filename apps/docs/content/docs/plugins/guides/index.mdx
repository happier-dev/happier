Choose the smallest task that describes the outcome. A declaration describes a
cold catalog fact; an activation registration supplies only the dynamic leaf
that its declaration requires. The host retains installation trust, lifecycle,
identity, and user-facing state.

Use the [manifest contribution reference](/plugins/manifest/contributions)
to project a cold descriptor, [runtime services](/plugins/services) for
bounded work during an invocation, and [testing](/plugins/testing) before
claiming a loaded flow works. The generated [capability matrix](/plugins/manifest/availability)
is the authority for source availability, loaded-platform proof, and publication
status; these task links do not maintain a second availability list.
