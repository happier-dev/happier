---
title: Managed servers
description: Supervise plugin-owned local servers through context.services.managed.
---

Use `context.services.managed.servers.supervise(...)` for plugin-owned loopback services. Declare managed dependencies and executable access in the cold manifest first.

The service can own process launch, explicit managed-spawn or external-attach mode, port and base URL projection, health checks, startup timeout, bounded credentials, durable log policy, snapshots, and cleanup.

```ts
const server = await context.services.managed.servers.supervise(spec, {
  signal: context.signal
});

await server.waitUntilHealthy({ signal: context.signal });
```

Dispose the returned handle with its activation, Agent runtime, or session owner.

## Good practices

- Bind managed servers to loopback.
- Generate narrow credentials for local HTTP services.
- Keep external-attach and managed-spawn modes explicit.
- Redact durable logs.
- Fail closed when post-start health or authentication validation fails.
