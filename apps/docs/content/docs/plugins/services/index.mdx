---
title: Runtime services
description: Host-provided services available through PluginInvocationContext.
---

Invoked handlers use `context.services` from `PluginInvocationContext`. Native
Agent session and execution-run operations receive their own bounded contexts.
Activation itself is registration-only and has no services.

Use host services for portability, cancellation, cleanup, diagnostics, managed
binaries, and Happier-owned resources. For trusted daemon code, filesystem,
network, environment, and process helpers are cooperative facilities rather
than a security sandbox.

## Principles

- Check `context.services.availability(serviceId)` where host or lifetime
  support can vary.
- Honor `context.signal` and method-level abort signals.
- Treat coded denial/unavailable results as distinct from arbitrary direct code
  access.
- Keep session, transcript, queued-input, activity, and process lifecycle with
  the host.
- Use `context.ui` for present-user questions and presentation intent.
