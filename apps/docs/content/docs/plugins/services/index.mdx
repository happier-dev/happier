---
title: Runtime services
description: Host-provided services available through PluginContextV1.
---

Runtime services are exposed through `PluginContextV1`. They are the supported way for plugin code to interact with host capabilities.

Use runtime services instead of reading Happier internals, spawning unmanaged processes, writing host state files directly, or maintaining agent-local duplicates of host systems.

## Service principles

- Services are scoped to the invoking plugin, agent runtime, session, or operation.
- Services return typed results and diagnostics.
- Long-running methods should honor abort signals.
- Services expose focused reads instead of full host read models.
- Disposables should be idempotent.
