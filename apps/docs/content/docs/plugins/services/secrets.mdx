---
title: Secrets service
description: Store plugin secrets without exposing secret values through settings or projection.
---

`ctx.secrets` stores sensitive plugin values.

## Operations

- get a secret by name
- set a secret
- delete a secret
- list secret names

Listing returns names only. It should not expose values.

## Rules

- Do not store tokens in settings.
- Do not log secret values.
- Do not project secret values into UI descriptors.
- Use connected-service materialization when a provider needs account-scoped credentials.

## Secret vs auth materialization

Use `ctx.secrets` for plugin-owned secret values. Use `ctx.auth.services.materialize(...)` for host-managed connected-service credentials.
