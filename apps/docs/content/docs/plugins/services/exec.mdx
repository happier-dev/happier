---
title: Exec service
description: Launch declared processes and protocol clients through the binary-safe host runtime.
---

Use `context.services.exec` to resolve system tools, check Agent CLI readiness, run or spawn declared executables, and create supported protocol clients.

Happier ships binary installers and must work without a system Node.js runtime or package manager. The exec service centralizes managed executable resolution, bounded output, cancellation, lifecycle, and binary-safe platform behavior.

## Main surfaces

- `agentCli.checkReadiness(...)`
- `systemTools.resolve(...)`
- `run(request, options?)` for bounded execution
- `spawn(request, options?)` for a disposable process handle
- `clients.spawn(spec, options?)` for JSON-RPC, JSON stream, framed byte, or loopback WebSocket clients

## Rules

- Reference declared managed executables; do not construct ambient executable paths.
- Never spawn raw Node.js or package-manager commands from shipped plugin runtime paths.
- Bound captured output and do not log secrets or raw credential-bearing command lines.
- Honor abort signals and dispose process or protocol-client handles with their owning runtime.
- Treat `wait()` as observed process evidence; do not publish host-owned terminal session state directly.
