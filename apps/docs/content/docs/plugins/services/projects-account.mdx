---
title: Projects and account
description: Read project/workspace references and account settings through host services.
---

`ctx.projects` exposes workspace references. `ctx.account.settings` exposes account settings.

## Project reads

Plugins can:

- list all workspace refs
- list refs for the current machine
- list refs for a specific machine
- get a ref by key
- get the active workspace
- watch project changes

## Account settings

Plugins can read and update account settings through the host service.

## Freshness

Account-settings freshness is host behavior. Plugins should consume the host snapshot/subscription and should not maintain a second daemon refresh channel.
