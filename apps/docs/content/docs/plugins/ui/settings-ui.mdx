---
title: Host-rendered plugin UI
description: Use declarative settings, status, and actions without shipping renderer code.
---

Host-rendered UI is the simplest choice for settings, setup, status, and
actions. The manifest supplies typed descriptors; Happier renders accessible
controls with the current platform's native components.

Use this mode when the UI can be expressed as fields, groups, options, status,
and actions. It avoids a separate executable UI bundle and inherits host focus,
keyboard, screen-reader, contrast, Dynamic Type/zoom, RTL, and reduced-motion
behavior.

Invoked handlers read or update settings through
`context.services.settings`. Secret values use the host-owned secrets service,
not a plain settings or storage field. Agent-targeted configuration is declared
through the canonical typed settings model and materialized by the host for the
native `AgentRuntime` session request.
