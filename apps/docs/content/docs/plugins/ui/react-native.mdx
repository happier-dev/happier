---
title: React Native UI
description: Build trusted, native-feeling plugin UI for supported Happier clients.
---

React Native is the default executable UI model when a plugin needs a native-feeling, host-integrated surface. Its code is part of the trusted plugin package and runs in the supported client realm; it is not sandboxed.

## Scaffold

```bash
happier plugins scaffold ./my-plugin \
  --id com.example.my-plugin \
  --name "My plugin" \
  --ui reactNative

cd my-plugin
happier plugins dev
```

The generated project includes the manifest contribution, React Native source, compatible build dependencies, and a public SDK build configuration. Keep the generated dependency and compatibility versions aligned unless a newer SDK release documents a migration.

## Host API

Export a `PluginUiRenderSurface`. Happier supplies its
`PluginUiRenderContext`, including the already-bound `hostApi`, directly:

```tsx
import type { PluginUiRenderSurface } from '@happier-dev/plugin-sdk/ui';

export const renderSurface: PluginUiRenderSurface = ({
  hostApi,
  surface,
  signal,
}) => {
  // Use hostApi from event handlers, honor signal for asynchronous work,
  // and render from the supplied accessibility/environment values.
  return null;
};
```

`@happier-dev/plugin-sdk/ui/client` is the hosted-web bootstrap client; do not
use it from a React Native renderer. Do not pass a host-internal surface or
transport object, and do not import Happier app internals.

## Accessibility and offline snapshots

Use React Native accessibility roles, labels, hints, state, and live regions,
and preserve a logical reading and focus order. Render from the supplied
`surface` values for locale, direction, color scheme, contrast, text scale,
reduced motion, screen-reader state, and safe-area insets. Support Dynamic
Type, RTL and long strings, high contrast, reduced motion, and 44×44-point iOS
or 48×48-dp Android targets.

The host owns generation currentness. Do not retain a competing currentness
flag or call host methods after `signal` aborts. If a host operation becomes
unavailable, preserve useful rendered state and present a recoverable status
instead of assuming the mutation succeeded.

While disconnected, Happier can retain the mounted visual tree as a
non-interactive snapshot. It blocks pointer, touch, keyboard, focus,
accessibility actions, and host API mutations, then exposes a localized
host-owned static summary using the surface's declared display title. Provide
a meaningful localized title and make the last rendered visual state
understandable without requiring a control. Reconnect supplies a revalidated
context before interaction resumes.

## Build output

For a production artifact, `happier plugins author build .` writes the portable
UI artifact tree under `dist/happier-plugin-ui`. React Native targets use
public presets from `@happier-dev/plugin-sdk/ui/build`; supported web output
uses React Native Web from the same authoring model.

The manifest declares surface identity, placement, compatibility, and artifact references. `ui-artifacts.json` describes the emitted files and digests. Authors do not hand-author the final content digest.

## Boundary

The host owns navigation, permissions, app state, session lifecycle, and native services. Use the Plugin UI host API for supported interactions. Whole-package Install & Trust covers this client code, daemon code, dependencies, and build artifacts together.
