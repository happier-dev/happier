---
title: Transcript dispatch facet
description: Let the host route outbound transcript behavior through agent-owned dispatch policy.
---

The transcript dispatch facet lets an agent runtime influence outbound transcript behavior without owning the whole transcript system.

Use it when an agent needs agent-specific metadata enrichment, tool normalization, trace events, or post-send effects.

## Boundary

The agent leaf can supply dispatch policy. The host still owns durable transcript writes, encryption envelopes, ordering, retries, and projection to clients.

## Good use cases

- agent-specific tool trace normalization
- agent-specific metadata enrichment
- agent-runtime session id publication
- post-send evidence that needs a typed host path
