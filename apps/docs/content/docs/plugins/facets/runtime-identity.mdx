---
title: Runtime identity
description: Publish normalized runtime descriptor, capabilities, and facets for sessions and execution-runs.
---

Runtime identity tells Happier which agent runtime is actually running a session or execution-run.

## Published facts

Runtime identity can include:

- agent id
- runtime target
- runtime descriptor
- runtime capabilities
- runtime facets
- provider session id
- execution-run identity when relevant

## Why it matters

Runtime identity powers:

- resume and attach decisions
- UI status and details
- agent-specific settings display
- execution-run public state
- debugging and diagnostics

## Ownership

Agent leaves expose the facts they know. The host normalizes and publishes them through the runtime identity publication path.
