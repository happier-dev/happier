---
title: Session state facet
description: Publish agent-owned session state through host-registered fields.
---

The session state facet lets an agent runtime expose structured state that the host can validate and publish.

## Examples

- current model id
- active agent mode
- agent-runtime session descriptor
- work state
- usage-limit recovery state
- connected-service runtime identity

## Durable writes

Durable session state writes should go through host-owned registered field paths. Agent leaves should not write arbitrary metadata directly when a registered field exists.

## Capability shape

Agents should declare session-state capabilities so the host can project availability and reject unsupported updates.
