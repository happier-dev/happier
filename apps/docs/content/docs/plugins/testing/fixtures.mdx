title: Fixtures
description: Use public SDK examples and runtime fixtures as plugin validation references.
---

Useful fixture families live in the repo:

- public SDK examples under `packages/plugin-sdk/examples/public-authoring/`
- CLI plugin authoring examples under `apps/cli/src/plugins/testkit/fixtures/authoring-examples/`
- first-party plugins under `packages/plugins/<pluginId>/`

Use public SDK examples for author-facing imports. Use CLI fixtures to validate host runtime behavior.
