title: Debugging

---

## Common failure classes

- manifest schema invalid
- undeclared handler id
- missing runtime capability family
- missing permission grant
- untrusted source
- activation exception
- stale development build or daemon source observation
- agent binary unavailable
- managed service health check failure
- agent auth unavailable
- runtime event schema invalid
- process disposal leak

## Debugging approach

1. Validate manifest projection first.
2. Confirm the daemon is observing the expected development source and build output.
3. Confirm activation registrations match manifest ids.
4. Run the smallest handler or agent runtime flow.
5. Inspect daemon/plugin logs.
6. Add focused tests for the observed failure.
