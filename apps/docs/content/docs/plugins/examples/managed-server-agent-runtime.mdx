---
title: Managed server Agent runtime example
description: Supervise an Agent-owned loopback server through public services.
---

Use `context.services.managed.servers` when an Agent needs a local HTTP or protocol server.

1. Declare the managed dependency and required host access in the cold manifest.
2. Resolve external-attach or managed-spawn mode.
3. Call `context.services.managed.servers.supervise(spec, { signal })`.
4. Wait for `handle.waitUntilHealthy(...)` before creating the Agent client.
5. Dispose the handle with the owning Agent runtime or session.

Use loopback binding, narrow generated credentials, startup timeouts, redacted durable logs, and fail-closed health validation. The returned handle is the lifecycle owner for the supervised instance; do not build a second watcher or process registry.
