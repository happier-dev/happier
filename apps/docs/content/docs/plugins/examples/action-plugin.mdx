---
title: Action plugin example
description: A plugin that exposes one manifest-declared action.
---

Use this shape for a simple operation that can be called from CLI, MCP, or a session-agent surface.

## Manifest

Declare the action under `contributes.actions[]`.

## Activation

Bind the handler with `api.actions.register(id, handler)`.

## Runtime services

If the action needs plugin-owned state or diagnostics, use
`context.services.storage`, `context.services.settings`,
`context.services.logger`, or `context.services.events`. User interaction and
presentation use `context.ui`. Do not read host internals directly.
