---
title: Agent runtime plugin example
description: A plugin that contributes a custom AI agent runtime.
---

An agent runtime plugin declares an agent and registers a runtime.

## Manifest

Declare:

- `contributes.agents[]`
- agent id
- catalog ids when applicable
- `runtime.kind`
- agent runtime capabilities

## Activation

```ts
export async function activate(api) {
  api.agents.register('example', () => ({
    sessions: {
      open: (request, context) => createSessionRuntime(request, context)
    }
  }));
}
```

## Host boundary

The runtime creates agent execution objects. The host owns session and execution-run orchestration.
