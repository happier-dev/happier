---
title: Agent runtime plugin example
description: A plugin that contributes a custom AI agent runtime.
---

An Agent runtime plugin declares an Agent and, only for `runtime.kind: 'custom'`,
supplies a runtime factory. Generated activation binds it. Declarative ACP has
no factory or registration; use the
[Agent-mode guide](/plugins/guides/agent-modes) first.

## Declaration

Declare:

- `agents.<id>.declaration`
- agent id
- catalog ids when applicable
- `runtime.kind`
- agent runtime capabilities

## Code-defined declaration

The runner leaf defines and exports the factory. It imports only public SDK
types and owns no process-global state, because the daemon activation entry and
the runner can load in separate realms:

```ts
// src/agentRuntime.ts — the import-safe Session runner leaf
import type {
  AgentRuntimeFactory,
  AgentSessionRuntime,
  AgentSessionRuntimeEvent,
} from '@happier-dev/plugin-sdk/agents/runtime';

/** The events this leaf publishes, before the host stamps identity and ordering. */
type RuntimeEventInput = AgentSessionRuntimeEvent extends infer Event
  ? Event extends AgentSessionRuntimeEvent
    ? Omit<Event, 'sequence' | 'sessionId' | 'emittedAtMs'>
    : never
  : never;

export const createExampleAgentRuntime: AgentRuntimeFactory = () => ({
  sessions: {
    open(_request, context) {
      const listeners = new Set<(event: AgentSessionRuntimeEvent) => void>();
      let sequence = 0;
      const emit = (event: RuntimeEventInput): void => {
        const published = Object.freeze({
          ...event,
          sequence: ++sequence,
          sessionId: context.session.id,
          emittedAtMs: Date.now(),
        }) as AgentSessionRuntimeEvent;
        for (const listener of listeners) listener(published);
      };

      return {
        async send(request) {
          if (request.delivery.kind !== 'newTurn') {
            const diagnostic = {
              code: 'example_delivery_unsupported',
              severity: 'error' as const,
              message: 'This example accepts only new-turn delivery.',
            };
            emit({ kind: 'input-rejected', inputIds: request.inputIds, diagnostic, retryable: false });
            return { status: 'unsupported', diagnostic, retryable: false };
          }
          emit({ kind: 'input-accepted', inputIds: request.inputIds, delivery: request.delivery });
          emit({
            kind: 'message-delta',
            turnId: request.delivery.turnId,
            channel: 'assistant',
            text: `Echo: ${request.input.text}`,
          });
          emit({ kind: 'turn-complete', turnId: request.delivery.turnId });
          return { status: 'admitted' };
        },
        watch(listener) {
          listeners.add(listener);
          return { dispose: () => { listeners.delete(listener); } };
        },
        async dispose() {
          listeners.clear();
        },
      } satisfies AgentSessionRuntime;
    },
  },
});
```

The daemon entry declares the Agent, binds that factory through generated
activation, and names the same factory through the runner locator:

```ts
// src/index.ts — the daemon activation entry
import { definePlugin } from '@happier-dev/plugin-sdk';

import { createExampleAgentRuntime } from './agentRuntime.js';

export const { manifest, activate } = definePlugin({
  id: 'com.example.runtime',
  version: '0.1.0',
  entrypoints: { daemon: './dist/index.js' },
  agents: {
    example: {
      declaration: {
        title: 'Example runtime',
        runtime: { kind: 'custom' },
        primary: 'sessions',
        capabilities: {
          sessions: {
            open: ['create'],
            delivery: ['newTurn'],
            cancel: false,
          },
        },
      },
      factory: createExampleAgentRuntime,
      sessionRunnerFactory: {
        module: './agentRuntime.js',
        export: 'createExampleAgentRuntime',
        runtimeApiVersion: 1,
      },
    },
  },
});
```

A Session-capable custom Agent requires the `sessionRunnerFactory` locator
that names a distinct import-safe leaf exporting this exact factory. An
execution-run-only Agent registers an `executionRuns` factory instead and has
no locator. `definePlugin` generates the matching registration-only `activate`
ABI. The runner imports its leaf and never calls `activate`, so neither relies
on a process-global singleton shared with activation.

After `hdev plugins create`, use the minimal executable
[`session-agent`](https://github.com/happier-dev/happier/tree/v0.3/packages/plugin-sdk/examples/session-agent)
reference for a custom persistent Session Agent. It proves public registration,
create and exact-provider-id resume, strict reasoning/assistant/tool events, a
host interaction, cancellation, and a truthful unsupported native-fork
capability. Its README owns the full source/archive, reload/restart,
disable/revoke/reinstall/uninstall journey and shared UI selectors. Use
`advanced-package-root` only for its additional composite capabilities.

## Host boundary

The runtime creates agent execution objects. The host owns session and execution-run orchestration.
