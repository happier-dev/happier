---
title: ACP Agent runtime example
description: A native AgentRuntime that composes an ACP session.
---

Use the public ACP composer when the Agent speaks Agent Client Protocol.

1. Declare the Agent under `contributes.agents` in the cold manifest.
2. Register its factory with `api.agents.register(localId, factory)`.
3. Return an `AgentRuntime` with a `sessions.open(request, context)` method.
4. Inside `open`, call `context.protocols.acp.open(request, options)` and return the resulting `AgentSessionRuntime`.

Put Agent-specific transport, authentication, model, timeout, tool, stderr, and extension behavior in the ACP options. The host retains shared session, input, transcript, activity, and persistence ownership.
