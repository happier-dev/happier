title: ACP agent runtime example
description: A agent runtime plugin that uses the SDK ACP substrate.
---

Use the ACP substrate when the agent speaks Agent Client Protocol and can be described with an ACP spec.

## Pattern

1. Declare an agent in the manifest.
2. Register an agent runtime.
3. In the runtime factory, call `ctx.acp.defineAcpBackend(spec)`.
4. Return or delegate to the ACP runtime's `runtimeCore`.

## Agent-specific callbacks

Put argv, environment, preflight, and permission-decision shaping in the ACP spec callbacks.
