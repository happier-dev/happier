Happier bundles 43 plugins. That number is the clearest statement
of how this version is built: the coding agents, the model providers, the voice
engines, both version-control backends and all four hosting forges are plugins,
loaded through the same manifest, trust and activation path your own plugin
would use.

They are not a privileged tier. A bundled plugin declares its contributions in a
manifest, gets projected into catalogs without its code being executed, and
activates the same way. Reading one is the most useful thing you can do before
writing your own.

### Review agents

Review CLIs rather than general coding agents — no model choice, no resume.

| Plugin | Id | What it does |
| --- | --- | --- |
| **CodeRabbit review engine** | `happier.review.coderabbit` | Runs CodeRabbit as a review-only execution engine. |
| **DeepSec review engine** | `happier.review.deepsec` | Runs DeepSec as a review and security-review execution engine. |

### Model providers

Model sources that compatible agents can draw from, configured under **Settings → Providers**.

| Plugin | Id | What it does |
| --- | --- | --- |
| **CLIProxyAPI** | `happier.provider.cliproxyapi` | Use models served by an external or locally detected CLIProxyAPI gateway. |
| **DeepSeek** | `happier.provider.deepseek` | Use DeepSeek models through Anthropic- or OpenAI-compatible agents. |
| **LM Studio** | `happier.provider.lmstudio` | Use models served locally by LM Studio 0.4.1 or newer. |
| **MiniMax** | `happier.provider.minimax` | Use MiniMax models through compatible agents on the global or China endpoint. |
| **Ollama** | `happier.provider.ollama` | Use models served locally by Ollama. |
| **OpenAI** | `happier.provider.openai` | Use OpenAI API models through a SavedSecret-backed provider connection. |
| **OpenRouter** | `happier.provider.openrouter` | Use OpenRouter models through one provider connection. |
| **Z.AI** | `happier.provider.zai` | Use Z.AI Coding Plan models through compatible agents. |

### Version-control backends

The systems Happier can read and write a working copy through.

| Plugin | Id | What it does |
| --- | --- | --- |
| **Git SCM backend** | `happier.scm.backend.git` | First-party local Git SCM backend. |
| **Sapling SCM backend** | `happier.scm.backend.sapling` | Provides the first-party local Sapling SCM backend with audited limited capabilities. |

### Hosting providers

Pull requests, issues and repository events, per forge.

| Plugin | Id | What it does |
| --- | --- | --- |
| **Azure DevOps SCM hosting provider** | `happier.scm.forge.azure-devops` | Detects Azure DevOps remotes, provides Azure Repos operations, and brings its pull requests into PRs & Issues. |
| **Bitbucket SCM hosting provider** | `happier.scm.forge.bitbucket` | Detects Bitbucket Cloud remotes, provides repository operations, and brings its pull requests into PRs & Issues. |
| **GitHub SCM hosting provider** | `happier.scm.forge.github` | Detects GitHub remotes and provides GitHub repository operations. |
| **GitLab SCM hosting provider** | `happier.scm.forge.gitlab` | Detects GitLab remotes and provides GitLab repository operations. |

### Conversation channels

Places a session can talk to people outside Happier.

| Plugin | Id | What it does |
| --- | --- | --- |
| **Discord Channels** | `happier.channel.discord` | Connects Discord conversations to Happier Channels. |
| **Telegram Channels** | `happier.channel.telegram` | Connects Telegram bot conversations to Happier Channels. |

### Everything else

Single-purpose plugins that do not belong to a family.

| Plugin | Id | What it does |
| --- | --- | --- |
| **Conversation Channels** | `happier.channels` | Connects external conversations to Happier sessions and automations. |
| **Plugin Inspector** | `happier.inspector` | First-party Plugin SDK inspector for installed plugin state and reload diagnostics. |
| **PostHog** | `happier.posthog` | Brings PostHog error issues into PRs & Issues with their own detail body. |
| **PRs & Issues** | `happier.triage` | Aggregates pull requests, issues and error groups from configured sources into one reviewable surface. |
| **Sentry** | `happier.sentry` | Brings Sentry error issues into PRs & Issues with their own detail body. |
