title: Plugin manifest
description: The strict cold JSON source of truth for plugin identity and contributions.
---

Every external plugin is described by:

```text
.happier-plugin/plugin.json
```

Happier reads and validates this file before importing plugin code. The same
canonical schema is used by the scaffold, development loop, build, pack, and
install paths. Unknown behavior keys reject with a path-specific diagnostic;
only an explicitly documented metadata extension point may accept unknown JSON.

The canonical publication URL for editors and authoring tools is the
[Plugin Manifest v2 JSON Schema](https://happier.dev/schemas/plugin-manifest-v2.json).
The repository's website artifact is generated from the same Protocol owner,
but deployment of that route remains a preview release gate. Until it is live,
use the scaffolded protocol-generated copy beside `plugin.json` at
`plugin.schema.json`.

## Minimal shape

The default scaffold emits one action and two executable entrypoints:

```json
{
  "schemaVersion": 2,
  "id": "com.example.plugin",
  "version": "0.1.0",
  "displayName": "Example plugin",
  "description": "Local Happier plugin scaffold for Example plugin.",
  "engines": { "happier": "^0.2.0" },
  "runtime": { "apiVersion": 1 },
  "entrypoints": {
    "daemon": "./dist/index.js",
    "development": "./src/index.ts"
  },
  "contributes": {
    "actions": [
      {
        "id": "save-note",
        "title": "Save note",
        "description": "Returns the supplied note from one minimal plugin action.",
        "scopes": ["global"],
        "surfaces": ["agent", "cli", "mcp"],
        "placement": "commandPalette",
        "dangerLevel": "safe",
        "inputSchema": {
          "type": "object",
          "additionalProperties": false,
          "properties": { "note": { "type": "string" } },
          "required": ["note"]
        },
        "resultSchema": {
          "type": "object",
          "additionalProperties": false,
          "properties": { "note": { "type": "string" } },
          "required": ["note"]
        }
      }
    ]
  }
}
```

Ordinary contributions activate on demand.

## Authority and identity

- Authors declare a plugin id and contribution-local ids.
- Happier owns structured `{ pluginId, localId }` identity.
- Use `<pluginId>/<localId>` only at global CLI, wire, and display boundaries.
- Do not dot-concatenate the two ids or repeat the plugin id inside a local id.

`entrypoints.daemon` names the compiled, self-contained installed module.
`entrypoints.development` names the TypeScript source module selected by
`happier plugins dev`. Static discovery, review, and catalog projection do not
import either module.

## TypeScript

`PluginManifest` is exported from `@happier-dev/plugin-sdk/manifest` for typed
fixtures and tools. External discovery still reads JSON; there is no supported
executable TypeScript manifest path.
