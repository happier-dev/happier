## Authoring source

```text
my-plugin/
  src/
    index.ts
    ui/                       # when the selected UI mode needs it
  test/
    index.test.mjs
  package.json
  tsconfig.json
```

`src/index.ts` is code-defined authoring source. It exports the `manifest` and
`activate` projection from `definePlugin(...)`; authors do not maintain a
second checked-in `.happier-plugin/plugin.json`. Development source may have
ordinary dependencies managed by `hdev plugins dev`. It is not itself the
installable production artifact.

## Installable package

An installable plugin is an npm-compatible tarball. Its `package.json` contains:

- a valid package name and version;
- `happier.manifest: ".happier-plugin/plugin.json"`;
- the `happier-plugin` keyword;
- a deliberate `files` inventory;
- compiled, self-contained daemon and declared UI artifacts.

The default scaffold uses a deliberate runtime `dist` inventory and includes
its generated `.agents/skills/happier-plugin-authoring` guide as authoring
documentation. The canonical pack owner derives and stages
`.happier-plugin/plugin.json` into the archive from the author module.
Production plugins must not depend on lifecycle scripts, runtime dependency
installation, or a system package manager on the target machine.

## Daemon entry

The daemon module uses the code-defined author helper, which emits the named
activation export consumed by the host:

```ts
import { definePlugin } from '@happier-dev/plugin-sdk';
import {
  defineProtocolObject,
} from '@happier-dev/plugin-sdk/protocol';

export const { manifest, activate } = definePlugin({
  id: 'com.example.my-plugin',
  version: '0.1.0',
  entrypoints: { daemon: './dist/index.js' },
  displayName: 'My plugin',
  actions: {
    'save-note': {
      title: 'Save note',
      execution: { target: 'daemon' },
      inputSchema: defineProtocolObject({}, { policy: 'closed' }),
      async run() { return {}; },
    },
  },
});
```

## UI choices

- React Native is trusted executable package code and is the default
  cross-platform renderer.
- Packaged hosted web availability is per host: each host reports the one frame
  adapter it constructed, or a typed unavailable reason.
- Declarative settings, status, and actions are rendered entirely by the host.

Generated UI artifacts belong in the selected `dist` tree. Authors do not
maintain executable artifact inventory rows or digests by hand.

## Exclude

- secrets or account tokens;
- absolute build-machine paths;
- source, tests, or caches outside the deliberate package inventory;
- imports from Happier internal workspaces or another plugin's source;
- runtime dependence on Node/npm/pnpm/yarn executables supplied by the user.
