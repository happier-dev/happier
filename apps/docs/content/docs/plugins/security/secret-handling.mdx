---
title: Secret handling
description: Keep credentials and sensitive material out of projection and logs.
---

Use `ctx.secrets` for plugin-owned secrets and `ctx.auth.services.materialize(...)` for host-managed connected-service credentials.

## Rules

- Never store secrets in manifest, settings, UI descriptors, or plugin storage.
- Never emit secrets in events, artifacts, telemetry, or logs.
- Redact startup diagnostics and durable logs.
- Treat native agent transcript files and session bundles as potentially sensitive.
- Delete temporary credential files during disposal when the host service does not own them.
