---
title: Secret handling
description: Keep credentials and sensitive material out of projection and logs.
---

Use `context.services.secrets` for plugin-owned secrets. Use
`context.services.connectedAccounts.materialize(purpose, request)` for narrowly scoped,
host-managed account credentials.

## Rules

- Never store secrets in the manifest, settings, UI descriptors, or ordinary plugin storage.
- Never emit secrets in events, artifacts, telemetry, diagnostics, or logs.
- Redact executable output and durable logs.
- Treat Agent transcript files and session bundles as potentially sensitive.
- Request only the credential form and scope required for the current operation.
- Treat each Connected Accounts materialization as a point-in-time snapshot. On an opaque resync, discard reliance on the prior snapshot and materialize again.
- Delete plugin-owned temporary credential files during disposal; do not retain material supplied for one operation.
