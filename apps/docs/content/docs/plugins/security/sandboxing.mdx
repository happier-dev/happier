---
title: Isolation and boundaries
description: Know which Plugin Platform surfaces are isolated and which are trusted code.
---

Happier plugins are trusted code packages. The Plugin SDK is a supported interface, not a security sandbox.

## Trusted executable code

- Daemon entrypoints run as trusted local code.
- React Native plugin UI runs as trusted client code.
- Dependencies and build outputs belong to the same package trust decision.

Bundled and externally installed plugins are eligible for the same host
capabilities; each plugin still receives the services and contributions its
manifest and activation declare. Eligible host Actions start **Allowed** on the
**Trusted plugins** integration; a present user can change an individual Action
to **Ask first** or **Off** under **Settings → Actions → Integrations**. Happier
stamps the calling plugin and its current activation generation, so a plugin
cannot impersonate another plugin, a retired generation, or the present user.
Approval decisions and security controls that require a present user remain
discoverable where useful but return `present_user_required` to plugin
automation.

Manifest host-access requests constrain host-mediated services. They do not prevent trusted code from using ambient process capabilities, so review package source and dependencies before selecting **Install & Trust**.

## Isolated UI

Packaged hosted web renders inside a host-constructed frame adapter where the host reports one, and is unavailable with a typed reason where it does not. That iframe or WebView boundary limits the UI's direct access to Happier client internals, but it does not sandbox daemon code or other executable code shipped by the same plugin.

## Declarative surfaces

Host-rendered settings and other declarative surfaces contain data the host validates and renders. Prefer them when arbitrary client code is unnecessary.

TypeScript types, manifest validation, artifact digests, and package layout improve correctness and reviewability. They are not substitutes for package trust.
