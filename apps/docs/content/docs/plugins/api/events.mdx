## Availability

The `events` declaration family and `/events` type entrypoint are source-level
public API. `context.services.events` remains deferred in the
[capability matrix](/plugins/manifest/availability). It is not supported or
advertised for ordinary author use; do not rely on it; consult its unblock
condition. The examples below describe the deferred contract, not a current
ordinary-author workflow.

## Deferred contract reference

The following shapes are what a maintained external development-source proof
must exercise through the current loaded development stack. Each event has a
plugin-local id and an optional payload schema. The host combines the trusted
plugin id and local id into structured `{ pluginId, localId }` identity.

## Emit an owned event

`emit` accepts the current plugin's local event id:

```ts
await context.services.events.plugin.emit('build-completed', {
  status: 'ok'
});
```

The event must be declared by the current plugin. Reserved host names, undeclared ids, and payloads that fail the declared schema are rejected.

## Subscribe

Dynamic subscriptions use a structured contribution reference:

```ts
const subscription = context.services.events.plugin.subscribe(
  { pluginId: 'com.example.build', localId: 'build-completed' },
  async (event) => {
    const payload = event.payload;
  }
);

subscription.dispose();
```

The target event and the caller's exact subscription target must be declared and active. No second host-access entitlement is required.

Manifest-declared subscription handlers use the `events.<subscriptionId>.handler`
field in `definePlugin(...)`; generated activation binds the same local id, not
the publisher's event id.

## Host events

Strict semantic host lifecycle events use `context.services.events.host.subscribe(...)` with a catalog-defined event id and either a current-session or explicit-session target. Raw Agent/provider messages are not exposed through this service.

## Delivery semantics if enabled

The typed contract has bounded delivery: it does not promise replay, history,
global ordering across publishers, or transcript persistence. Dispose dynamic
subscriptions with their owner and isolate subscriber failures from publisher
correctness. Those semantics do not make the service supported or advertised
for ordinary authors while its matrix row remains deferred.
