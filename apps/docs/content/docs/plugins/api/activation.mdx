---
title: Activation
description: Bind executable plugin behavior to manifest-declared local ids.
---

Ordinary plugin modules use `definePlugin(...)`. It is the single authoring
path: one declaration produces the cold manifest and the matching named
`activate` ABI without maintaining a second handwritten module.

```ts
import { definePlugin } from '@happier-dev/plugin-sdk';

export const { manifest, activate } = definePlugin({
  id: 'com.example.echo',
  version: '0.1.0',
  actions: {
    echo: {
      title: 'Echo',
      run: async (input) => input,
    },
  },
});
```

The generated activation is registration-only. It receives `PluginApi`, not
invocation or session services, and binds only ids declared in the matching
manifest family. Missing, undeclared, duplicate, or wrong-family registrations
fail validation.

Static manifest-declared registration methods return `void`. Dynamic watches
or subscriptions may return `Disposable` when their documented lifetime is
genuinely author-owned.

## Low-level ABI conformance

Handwriting `activate` is only for low-level ABI conformance or host-owned test
fixtures. It is not a second normal authoring path. A conforming module still
uses the same registration-only contract and may return one cleanup function
after successful registration:

```ts
import type { PluginApi } from '@happier-dev/plugin-sdk';

export async function activate(api: PluginApi) {
  const connection = await openPluginOwnedConnection();
  api.actions.register('query', (input) => connection.query(input));
  return async () => connection.close();
}
```

Happier calls a returned cleanup function at most once when that successful
activation is retired or later validation fails. If activation throws before
returning, no cleanup function exists yet. Protect directly acquired timers,
sockets, processes, and other trusted-code resources with local `try`/`finally`;
Happier can automatically unwind only registrations and resources acquired
through host APIs.

Do not perform user-visible effects, start Agent sessions, read secrets, or
write transcripts during activation. Those operations belong to invoked
handlers or native Agent session operations.
