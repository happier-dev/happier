---
title: ACP Agent runtimes
description: Compose a native AgentSessionRuntime for an Agent Client Protocol process.
---

Use the ACP composer when an Agent speaks Agent Client Protocol. The composer returns the same native `AgentSessionRuntime` used by any other session implementation; it does not introduce another public runtime layer.

The `AgentSessionRuntimeContext` exposes protocol composers through `context.protocols`:

```ts
import type { AgentRuntime } from '@happier-dev/plugin-sdk/agent-runtime';

export const runtime: AgentRuntime = {
  sessions: {
    async open(request, context) {
      return context.protocols.acp.open(request, {
        transport: {
          // Supply the declared ACP transport for this Agent.
        },
        definition: {
          mcp: {
            // Supply the Agent's supported MCP input policy.
          }
        }
      });
    }
  }
};
```

Use the exact transport and definition types exported by the installed SDK version; the abbreviated values above show ownership, not a copy-paste-complete transport.

Agent-specific authentication, model projection, timeouts, verified image input, tool-name shaping, stderr rules, and protocol extensions belong in the ACP definition. Happier still owns session and turn lifecycle, input custody, transcript persistence, activity, and terminal process facts.

If the Agent also supports execution-runs, expose the native `executionRuns` factory on the same `AgentRuntime`. Do not create a second public session or run state machine.
