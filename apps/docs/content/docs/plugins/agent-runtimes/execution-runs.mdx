---
title: Execution-runs
description: Implement bounded Agent execution through AgentExecutionRunRuntime.
---

An `AgentRuntime` can expose an `executionRuns` factory for host-owned tasks that are not ordinary interactive sessions.

```ts
import type { AgentRuntime } from '@happier-dev/plugin-sdk/agents/runtime';

export const runtime: AgentRuntime = {
  executionRuns: {
    async open(request, context) {
      return createExecutionRun({ request, context });
    }
  }
};
```

`AgentExecutionRunRuntime` implements:

- `send(input, options?)`
- `stop(options?)`
- `watch(listener)` returning a `Disposable`
- `dispose()`

Events carry a monotonically increasing sequence and one of the public run-start, progress, output, checkpoint, complete, failed, or cancelled shapes. Keep raw Agent protocol messages inside the adapter.

The host owns public run state, cancellation admission, status projection, and persistence. When sessions and execution-runs use the same Agent protocol, share the native adapter and parsing logic rather than maintaining competing protocol implementations.

For an Agent whose finite Run is backed by the same native Session runtime,
use the public adapter instead of implementing a second Run state machine:

```ts
import {
  createExecutionRunHostBackendFromSessionRuntime,
  type AgentRuntime,
} from '@happier-dev/plugin-sdk/agents/runtime';

export const runtime: AgentRuntime = {
  executionRuns: {
    async open(request, context) {
      return createExecutionRunHostBackendFromSessionRuntime({
        request,
        openSession: async () => openAgentSessionForRun(request, context),
      });
    },
  },
};
```

The adapter owns sequence assignment, replay, terminalization, cancellation,
and cleanup. The plugin owns Session opening and may project an Agent-native
checkpoint. Claude, OpenCode, Gemini, Pi, and Antigravity use this shared
adapter in the current source tree.

An execution-run-only custom Agent has no Session runner locator. A composite
Agent that also exposes `sessions` does: follow the persistent Session rules in
[Add an Agent](/plugins/guides/agent-modes).
