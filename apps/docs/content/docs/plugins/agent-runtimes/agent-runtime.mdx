---
title: Agent runtimes
description: The executable object that binds agent code to Happier runtime contracts.
---

`AgentRuntime` is the executable integration object for a manifest-declared agent.

```ts
type AgentRuntimeV1 = Readonly<{
  runtimeCore?: RuntimeCoreV1;
  facets?: RuntimeFacets;
  messageMeta?: AgentMessageMetaEnricherV1;
  terminalRuntimeSurface?: TerminalRuntimeSurfaceV1;
  externalSessionSurface?: ExternalSessionSurfaceV1;
  attachSurface?: AttachSurfaceV1;
  handoffSurface?: HandoffSurfaceV1;
  forkSurface?: ForkSurfaceV1;
  checkpointSurface?: CheckpointSurfaceV1;
}>;
```

## Registering a runtime

```ts
export async function activate(host) {
  host.registerAgentRuntime({
    agentId: 'example',
    create: (ctx) => createExampleAgentRuntime(ctx)
  });
}
```

`agentId` references an entry declared in `manifest.contributes.agents[]`. The manifest entry uses `id`; references use `agentId`.

## Runtime contents

A runtime can expose normal session execution through `runtimeCore`, adjacent product surfaces through agent runtime surfaces, and lower runtime integrations through facets.

Not every agent needs every field. An external-session-only agent might expose `externalSessionSurface` and no `runtimeCore`.

## Example pattern

```ts
export function createExampleAgentRuntime(ctx: PluginContextV1): AgentRuntime {
  return {
    runtimeCore: {
      createSessionRuntime: async (params) => createExampleSessionRuntime({ ctx, params }),
      createExecutionRunBackend: (params) => createExampleExecutionRunBackend({ ctx, params })
    }
  };
}
```

## Design rule

The runtime is an agent leaf. It should adapt agent-specific behavior into Happier contracts. It should not own host session lifecycle, durable transcript writes, execution-run public state, or UI status rules.
