---
title: Install and reload
description: How plugin install and reload affect runtime generations.
---

Install records a plugin source and validates its manifest. Reload rebuilds the executable runtime registry.

## Reload behavior

During reload:

- daemon modules are imported for a new generation
- activation runs against a fresh API host
- registrations are validated
- new runtime registry replaces the old registry on success
- old generation disposables are disposed
- activation failure keeps the previous working generation when possible

## Operational rule

Make activation and disposal idempotent. Runtime operations can be active while reload is requested.
