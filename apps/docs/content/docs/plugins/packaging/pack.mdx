---
title: Pack plugins
description: Create a selected-file npm-compatible Plugin Platform archive.
---

Packing creates an installable archive from a local plugin directory.

```bash
hdev plugins pack /absolute/path/to/plugin --out /absolute/path/to/plugin-output.happier-plugin.tgz
```

The package metadata identifies the generated cold manifest in `package.json`:

```json
{
  "keywords": ["happier-plugin"],
  "happier": { "manifest": ".happier-plugin/plugin.json" },
  "files": [".agents/skills/happier-plugin-authoring", "dist"]
}
```

Use a deliberate `files` inventory. The pack owner stages
`.happier-plugin/plugin.json` from the `definePlugin(...)` projection into the
archive even though authors do not keep that file in the source tree. Packing
includes only selected regular files and rejects unsafe archive paths and
package lifecycle assumptions.

The archive output must be outside the plugin package root and must not already
exist (including its `.sha256` sidecar). When no `--out` is supplied, use the
archive path printed by `plugins pack`.

The same pack step writes generated `happier.compatibilityProjection` and
`happier.marketplaceDiscovery` data into the staged `package.json`. Do not add
or maintain those fields in source metadata: they are derived from the
canonical manifest and generated UI inventory, including the exact staged
manifest digest.

## Include

- the generated `.happier-plugin/plugin.json` cold projection
- the compiled, self-contained daemon entry
- runtime resources
- built UI artifact tree
- files needed by declared handlers

## Exclude

- local secrets
- build caches
- absolute-path artifacts
- unrelated source-control metadata
- agent CLI binaries

## Validate the artifact

The default `hdev plugins test .` command is daemon-independent. Its
`--packed` mode packs the selected files, installs and trusts the archive in an
authenticated disposable daemon home, verifies activation and currentness
across daemon restart, and invokes a safe empty-input CLI action when the
manifest exposes one. It never reads or mutates the author's installed plugin
state. Before distribution, also validate any claimed user flows that extend
beyond this canonical packed smoke and verify uninstall on the relevant hosts.
