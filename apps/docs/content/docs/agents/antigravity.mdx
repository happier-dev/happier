Start an **Antigravity** session in Happier using the `agy` CLI on the selected
machine. Every session runs `agy acp`: with the machine's own sign-in, or with a
Connected Account or Gemini API key that Happier keeps in a private profile.

## Availability

This integration is experimental in 0.3 development builds.

## Requirements

Install a version of `agy` that supports `agy acp`. Sessions using a Connected
Account or a Gemini API key need `agy` 1.5.18 or newer; with an older CLI Happier
stops before the session starts and asks you to run `agy update`. Put `agy` on
`PATH` or set `HAPPIER_ANTIGRAVITY_PATH` to its absolute path.

## Install the Antigravity CLI

Happier ships the vendor's own install recipe and can run it for you from
**Settings → Agents → Antigravity**. When Happier drives the install it asks
first — running a vendor script is not something it will do silently.

In unreleased 0.3 development builds, Happier runs the CLI install and check
as a daemon job on the selected machine. See [install and update jobs](/agents#install-and-update-jobs-in-03-development)
for reconnecting, progress, and cancellation limits.

To install it yourself:

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
agy --version
```

On Windows, in PowerShell:

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

Google's own instructions are at
[antigravity.google/docs/cli-install](https://antigravity.google/docs/cli-install).

## Authentication

Open **Settings → Agents → Antigravity** and start the login on the machine that
will run the session. From a shell on that machine, run:

```bash
agy acp --login
```

Happier may show **Unknown** because Antigravity does not expose a safe background
sign-in check. If you set `GEMINI_HOME`, Happier passes it to `agy` as its profile
directory (`--gemini-dir`), because `agy` itself does not read the variable.

To supply a different account, choose a [Connected Account](/accounts/connected-services#google-antigravity-in-03-development)
when you start the session. Happier writes that account's token into a private
`agy` profile and tells `agy` to keep it there instead of the system keychain, so
the session never falls back to the machine's own sign-in. A Gemini API key also
runs in its own private profile, because `agy` remembers the API-key sign-in method
in the profile it uses.

## What Happier can drive

- **Model selection** shows the model families `agy` advertises with a separate
  reasoning-effort control. A saved choice from the older flat list (for example
  `gemini-4-neon-medium`) selects the matching family and effort.
- **Resume** uses the exact session ID. Conversations from earlier Happier
  releases, which ran Google's separate Antigravity ACP server, are copied into
  `agy`'s own store the first time you resume them; the originals stay in place.
- **Background commands** can finish after a
  reply. Their results update the original tool card. If Antigravity resumes
  generating, Happier shows a provider turn and asks for one-time approval
  when it cannot attribute a new tool request to a user prompt.
- **Session modes** come from authenticated ACP discovery. Choose an advertised
  starting mode in the new-session composer; it is applied before the first prompt.
  An unavailable discovery result does not create mode choices.
- **Handoff, listing and forking** are not supported.

## Terminal and existing CLI conversations

The terminal surface launches the interactive `agy` CLI on the selected machine.
Happier also observes Antigravity CLI transcripts so existing conversations show
up as external sessions you can read.

ACP sessions and `agy` CLI conversations are **separate identities**. Opening the
terminal from a Happier ACP session starts a fresh `agy` conversation rather than
reattaching to the ACP one, and external CLI sessions are read-only — Happier
does not claim writer safety or takeover for them.

Happier shows the models and context usage reported by the active ACP runtime.
Startup discovery can leave empty conversations in the provider's history.

## Troubleshooting

### "Antigravity not found"

Check the binary name — it is `agy`:

```bash
agy --version
```

If it is installed somewhere off `PATH`, point Happier at it directly:

```bash
export HAPPIER_ANTIGRAVITY_PATH=/absolute/path/to/agy
```

Happier ignores an override that does not point at an executable file, falling
back to `PATH` rather than reporting an error — so a typo here looks exactly
like no override at all.

### "Authentication required"

For machine sign-in, run `agy acp --login` on that machine. For a Connected Account
session, check that you selected the intended account and reconnect it if its
sign-in expired. For a Gemini API key, check the key itself.
