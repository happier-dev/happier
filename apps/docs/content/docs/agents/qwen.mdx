Happier supports Qwen as a local CLI-backed Agent.

## Requirements

- Qwen CLI installed locally.
- Binary available on `PATH` (or set `HAPPIER_QWEN_PATH`).

## Install Qwen

If you use hstack, you can install Qwen with its legacy-named `providers` installer:

```bash
hstack providers install qwen
qwen --version
```

Or install manually (macOS / Linux):

```bash
curl -fsSL https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.sh | bash
qwen --version
```

Windows (Run as Administrator in CMD):

```bat
curl -fsSL -o %TEMP%\\install-qwen.bat https://qwen-code-assets.oss-cn-hangzhou.aliyuncs.com/installation/install-qwen.bat && %TEMP%\\install-qwen.bat
qwen --version
```

## Local authentication in Happier

Qwen supports launching its native auth flow from:

- **Settings → Agents → Qwen Code**

Happier opens Qwen and sends `/auth` for you.

Auth-status detection for Qwen is currently conservative, so Happier may still show **Unknown** even though the login flow is available.

For the shared user guide, see [Agent authentication](/agents/provider-authentication).

## Start Qwen with Happier

```bash
happier qwen
```

## Custom model sources

Qwen's native [model provider configuration](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/model-providers/)
supports OpenAI Chat Completions, OpenAI Responses, Anthropic Messages, and Gemini
API endpoints. Configure these through Qwen's own settings and authentication flow.

Happier's 0.3 development integration does not yet expose a managed
[Provider connection](/agents/provider-integrations) binding for Qwen. Native
catalog entries can override endpoint and key choices passed at launch. Replacing
Qwen's system-settings file to force a binding would also discard the machine's
security, sandbox, and tool policies. A safe Session-only binding must preserve
those policies and keep its selected endpoint authoritative.

## Notes

- Resume availability is session-specific in Happier and depends on valid resume metadata plus the current backend/settings.
- Model, mode, and permission behavior can still vary by installed Qwen runtime.
- Tool calls are normalized to canonical Happier tool renderers.

## Troubleshooting

If Qwen is not detected:

1. Verify `qwen --version` works.
2. Restart Happier.
3. Set `HAPPIER_QWEN_PATH` if needed.
