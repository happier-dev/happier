**DeepSec** is a security review CLI rather than a general coding agent. Happier
runs it as a local CLI-backed Agent, but it offers no model choice and no
session resume, because the tool has neither.

## Requirements

- DeepSec CLI installed locally
- `deepsec` available on `PATH`, or `HAPPIER_DEEPSEC_PATH` set to its absolute path
- `AI_GATEWAY_API_KEY` in the environment the agent runs in

## Install DeepSec

Happier does not bundle an install recipe for DeepSec. Install it with whatever
method the vendor documents, then confirm Happier can see it:

```bash
deepsec --version
```

## Authentication

DeepSec has no login flow for Happier to launch. Happier reports it as signed in
when `AI_GATEWAY_API_KEY` is present in the environment the agent runs in.
Happier cannot verify the key works, only that it is set.

## What Happier can drive

- **Model selection** is not available — the tool does not offer one.
- **Resume**, **handoff**, **listing** and **forking** are not supported.
- **Session modes** are not exposed to Happier.

## Troubleshooting

### Status shows signed out with a key set

Happier reads the environment of the process the agent runs in, so a key
exported only in an interactive shell is invisible to a daemon started at login.
Set it where the service runs, then use **Check now**.
