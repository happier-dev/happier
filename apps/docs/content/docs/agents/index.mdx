Happier does not replace your coding agent. It runs the one you already use — on your own machine, in your own checkout — and gives you a way to watch it, steer it, approve its work and reply to it from anywhere.

Eighteen agents are wired up today. Whichever you pick, the parts that belong to Happier work the same way: the transcript, the pending queue, permissions and approvals, session settings, notifications, and the tools an agent can call. What differs is what each agent's own CLI exposes — which models it offers, whether it can resume a session, whether it accepts images.

Those differences are real and worth checking before you commit to a workflow. They live in one generated place:

## Getting an agent running

Each agent's page covers the same three things: installing its CLI, authenticating it, and the limits that will actually affect you. The shape is deliberately identical so you can move between them.

Three things are true for all of them:

- **You need the agent's CLI on the machine.** Happier detects what is already there and does not bundle an agent. Some agents have a managed install Happier can run for you, and the capability tables say which.
- **The upcoming 0.2 setup flow can guide installation.** When no agent is available, choose a catalog-backed agent or **Skip for now**. Skipping is valid, but a machine with no installed agent is connected rather than coding-ready.
- **Authentication belongs to the agent.** Happier reads its login state and, for some agents, can hold the credentials for you through [Connected Services](/accounts/connected-services) so you do not have to sign in separately on every machine.

Installing an agent and authenticating it are separate steps. After a managed install, follow that agent's page to complete its own sign-in before starting a session.

## Anything else that speaks ACP

For a CLI that is not on that list, Happier ships a generic **Custom ACP** family. You define selectable ACP backends once, and they then appear as ordinary agent choices everywhere in the app — the new-session picker, session settings, the lot.
