Happier is useful out of the box, but most of its reach comes from what you
connect to it.

## Giving agents more tools

- [MCP servers](/extending/mcp-servers) — browser automation, documentation lookup, internal APIs.
- [Happier tools and actions](/extending/happier-tools) — the actions agents can call inside Happier itself.
- [Prompts and skills](/extending/prompts-and-skills)
- [Installables](/extending/installables) — tools Happier can install and keep updated per machine.

## Delegating work

- [Delegated work](/extending/subagents) — subagents, workflows and Claude teams.

## Driving Happier from elsewhere

- [Happier as an MCP server](/extending/happier-as-mcp-server) — running Happier as an external stdio MCP server so an editor or an agent can start and manage sessions.
- [MCP host setup](/extending/mcp-hosts) — wiring that server into a specific editor or automation.
