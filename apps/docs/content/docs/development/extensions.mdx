The canonical author documentation lives under [Plugins](/plugins).

These authoring commands are available from the development lane through
`hdev`. The authoring flow is:

```bash
hdev plugins create my-plugin
cd my-plugin
hdev plugins dev
```

The workspace SDK remains private at `0.0.0`; use this flow with an approved
preview artifact. The complete empty-directory and live-host proof remains a
release gate.

The external manifest is cold JSON at `.happier-plugin/plugin.json`.
Executable daemon modules export a named `activate(api)` function. Invoked
handlers use `PluginInvocationContext`; native Agents implement `AgentRuntime`.
Happier owns session, turn, queued input, transcript, activity, persistence,
and process lifecycle.

Current author checks and packaging are:

```bash
hdev plugins dev typecheck .
hdev plugins dev build .
hdev plugins test .
hdev plugins pack .
hdev plugins install <archive-path> --kind archive
```

`plugins test .` runs the daemon-independent built-entrypoint smoke through the
public testkit, activates the plugin, and invokes the scaffold's declared
action. `plugins test . --packed` packs, installs, trusts, activates, and
optionally invokes the plugin through an authenticated disposable daemon, then
repeats the currentness and invocation checks after daemon restart. Neither
mode reads or mutates the user's installed plugin state. See
[Testing plugins](/plugins/testing) for the exact test layers and limits.
