This section is for people working **on** Happier rather than with it. If you
are here to use Happier, [Start here](/getting-started) is the page you want.

Happier runs as several workspaces in one repository — the clients, the CLI and
daemon, the relay, the plugin platform, and the shared contract packages between
them. Most changes touch more than one, which is why the local stack exists: it
runs the whole thing against your own checkout so you can see a change end to
end.
