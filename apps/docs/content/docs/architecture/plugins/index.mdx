title: Plugin platform architecture
description: How Happier validates, projects, activates, and executes plugins.
---

The plugin platform provides the host lifecycle around installable plugins.

## Responsibilities

- install and trust source records
- normalize and validate manifests
- project contribution registries
- build catalogs without executing plugin code
- load daemon plugin modules only after trust and validation
- provide `PluginApiV1` registration hosts
- construct `PluginContextV1` for invoked handlers
- manage runtime generations and reload
