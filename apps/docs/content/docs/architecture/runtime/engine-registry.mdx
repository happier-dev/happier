---
title: Agent runtime registry
description: Resolve manifest-declared Agents to registered native runtimes.
---

The Agent runtime registry is the host-owned resolver for executable Agent
contributions.

## Inputs

- normalized plugin Agent contributions
- registered native `AgentRuntime` factories
- Agent catalog entries
- host runtime params such as happy home dir and daemon-local services

## Output

The registry resolves one native runtime for an Agent identity. A runtime can
include:

- session factories
- execution-run factories
- optional typed Agent surfaces
- Agent-native message and provider-binding adapters

## Runtime context

The host creates bounded factory, session, and execution-run contexts only
after resolving the registered runtime. Invocation services stay out of cold
manifest projection and registration-only activation.

## Resolution rule

Selectable Agents resolve through this path. Production session and
execution-run code does not instantiate Agent-specific engines directly or
fall back to V1 runtime aliases.
