Happier runtime architecture separates product lifecycle from provider-specific execution.

## Layers

1. UI and client flows choose an Agent.
2. CLI daemon receives session or execution-run work.
3. The Agent catalog resolves the manifest contribution and registered native runtime.
4. The host constructs bounded Agent factory, session, or execution-run contexts.
5. Native `AgentRuntime` supplies session and/or execution-run factories.
6. Session or execution-run host bridge owns product lifecycle.
7. The Agent leaf maps Agent-native behavior into shared runtime contracts.

## Core invariant

The host owns lifecycle, permissions, pending queue behavior, transcript
projection, durable state, runtime identity publication, and user-facing
status. Agent leaves own Agent-native commands, codecs, correlation, and
authoritative evidence. Model Providers remain a separate domain.
