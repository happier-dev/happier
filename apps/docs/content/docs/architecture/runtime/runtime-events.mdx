---
title: Runtime events
description: Live runtime facts emitted by provider leaves and consumed by host projection paths.
---

`RuntimeEventV1` is the canonical lower runtime event payload. Provider leaves emit these events after mapping provider-native payloads.

## Event families

Runtime events can include:

- message deltas
- tool calls, tool results, and tool progress
- turn start, completion, failure, and cancellation
- provider turn id observations
- transcript-visible committed messages
- runtime status changes
- provider session id publication
- descriptor updates
- diffs and backend errors
- token counts
- context compaction lifecycle
- subagent start/status/end

## Boundary

Runtime events are live facts. They are not automatically durable transcript rows and they are not the public SDK event-bus envelope shape.

## Projection

The host decides which runtime events update transcript rows, session state, notifications, hooks, or UI status based on the owning product contract.
