# Notification sounds

Drop, Chime, Chord, Swell, Glow, Flutter, Pop, Blip, Tap, and Ping were created
by Dax Liniere and released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The files are levelled mono PCM WAV versions of the clips from
[Happier PR #1012](https://github.com/happier-dev/happier/pull/1012).
