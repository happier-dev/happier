# Agent Desktop attribution

Happier can download the unmodified native Agent Desktop command and its
platform helpers from the official upstream release.

- Upstream: https://github.com/vercel-labs/agent-desktop
- Release: https://github.com/vercel-labs/agent-desktop/releases/tag/v1.0.2
- License: Apache-2.0; the upstream text is retained in `agent-desktop-LICENSE`.
- Artifacts: `agent-desktop-v1.0.2-*.tar.gz` native release archives.
- Integrity: each platform archive is SHA256-pinned by the installable descriptor.

The complete archive payload is retained, including the macOS helper and Linux
clipboard owner where supplied. These release archives contain no license or
NOTICE file; Happier ships this attribution and the upstream license alongside
its other tool licenses. The upstream source has no separate NOTICE file.
