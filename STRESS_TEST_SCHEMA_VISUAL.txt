┌─────────────────────────────────────────────────────────────────────────────┐
│                          TABLE RELATIONSHIPS                                 │
└─────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────┐
    │     stress_test_run         │  ← Main results table
    │  (aggregated metrics)       │
    ├─────────────────────────────┤
    │ id: BIGSERIAL               │
    │ test_id: UUID (UNIQUE)      │
    │ start_time: TIMESTAMP (IDX) │
    │ end_time: TIMESTAMP         │
    │ total_duration_ms: INT      │
    │ bash_commands: INT          │
    │ files_created: INT          │
    │ subagents_spawned: INT      │
    │ web_searches: INT           │
    │ success_rate: DECIMAL(5,2)  │
    │ environment: VARCHAR(50)    │
    └──────────────┬──────────────┘
                   │
                   │ 1:M (CASCADE)
                   │
    ┌──────────────▼──────────────┐
    │  stress_test_operation      │  ← Optional detail table
    │   (individual operations)   │
    ├─────────────────────────────┤
    │ id: BIGSERIAL               │
    │ test_run_id: BIGINT (FK)    │
    │ operation_type: VARCHAR(50) │
    │ operation_index: INT        │
    │ start_time: TIMESTAMP       │
    │ end_time: TIMESTAMP         │
    │ duration_ms: INT            │
    │ success: BOOLEAN            │
    │ error_message: TEXT         │
    │ metadata: JSONB             │
    └─────────────────────────────┘

    ┌─────────────────────────────┐
    │ stress_test_metrics_daily   │  ← Pre-aggregated (for dashboards)
    │  (daily summaries)          │
    ├─────────────────────────────┤
    │ id: BIGSERIAL               │
    │ date_utc: DATE              │
    │ environment: VARCHAR(50)    │
    │ total_runs: INT             │
    │ total_duration_ms_sum: BIGINT
    │ avg_success_rate: DECIMAL   │
    │ avg_duration_ms: DECIMAL    │
    │ UNIQUE(date_utc, environment)
    └─────────────────────────────┘


┌─────────────────────────────────────────────────────────────────────────────┐
│                         INDEXING STRATEGY                                    │
└─────────────────────────────────────────────────────────────────────────────┘

    stress_test_run Indexes:
    
    ├─ idx_stress_test_run_start_time
    │  └─ (start_time DESC)  ◄─ Recent tests query
    │
    ├─ idx_stress_test_run_date_range
    │  └─ (start_time, end_time)  ◄─ Date range queries
    │
    ├─ idx_stress_test_run_test_id
    │  └─ (test_id)  ◄─ Direct lookups
    │
    ├─ idx_stress_test_run_created_at
    │  └─ (created_at DESC)  ◄─ Ordering by creation
    │
    ├─ idx_stress_test_run_date_env
    │  └─ (start_time DESC, environment)  ◄─ Environment + time filters
    │
    ├─ idx_stress_test_run_environment
    │  └─ (environment, created_at DESC)  ◄─ Environment trends
    │
    └─ idx_stress_test_run_failed  [PARTIAL: success_rate < 100.0]
       └─ (created_at DESC)  ◄─ Failed test reporting


┌─────────────────────────────────────────────────────────────────────────────┐
│                    CONSTRAINTS & DATA INTEGRITY                              │
└─────────────────────────────────────────────────────────────────────────────┘

    stress_test_run:
    ├─ success_rate BETWEEN 0.0 AND 100.0
    ├─ bash_commands_executed >= 0
    ├─ files_created >= 0
    ├─ subagents_spawned >= 0
    ├─ web_searches_performed >= 0
    ├─ successful_operations >= 0
    ├─ total_operations >= successful_operations
    └─ test_id UNIQUE

    stress_test_operation:
    ├─ test_run_id NOT NULL (FK → stress_test_run.id CASCADE)
    ├─ duration_ms >= 0
    └─ operation_type NOT NULL

    stress_test_metrics_daily:
    ├─ UNIQUE(date_utc, environment)
    ├─ total_runs >= 0
    ├─ avg_success_rate BETWEEN 0.0 AND 100.0
    └─ all sums/counts >= 0


┌─────────────────────────────────────────────────────────────────────────────┐
│                    COMMON QUERY PATTERNS                                     │
└─────────────────────────────────────────────────────────────────────────────┘

    Pattern                          Query Time   Index Used
    ─────────────────────────────────────────────────────────────
    
    Last 24 hours tests              <50ms        idx_stress_test_run_start_time
    Failed tests                     <50ms        idx_stress_test_run_failed (partial)
    Date range + environment         <100ms       idx_stress_test_run_date_env
    Specific test details            <5ms         idx_stress_test_run_test_id
    Daily metrics trend              <100ms       date/env composite
    Operation breakdown              <200ms       FK + operation_type


┌─────────────────────────────────────────────────────────────────────────────┐
│                    PERFORMANCE CHARACTERISTICS                               │
└─────────────────────────────────────────────────────────────────────────────┘

    Write Performance:
    ├─ Single test insert           ~5ms
    ├─ Batch 1000 operations        ~1s
    └─ Daily aggregation job        ~100ms

    Read Performance:
    ├─ Recent tests (24h)           <50ms
    ├─ Date range (7 days)          <100ms
    ├─ Failed tests list            <50ms
    └─ Complex aggregations         <500ms

    Storage:
    ├─ Per test row                 ~500 bytes
    ├─ Per operation row            ~200 bytes
    ├─ Indexes                      30-40% of table size
    └─ 1M tests + 10M ops           ~2-3GB


┌─────────────────────────────────────────────────────────────────────────────┐
│                       EXAMPLE DATA FLOW                                      │
└─────────────────────────────────────────────────────────────────────────────┘

    1. Record Test Run
       ├─ Create stress_test_run row
       │  └─ Calculate total_duration_ms (end - start)
       └─ Return testId for operations

    2. Record Operations
       ├─ For each operation:
       │  ├─ Calculate duration_ms
       │  └─ Insert stress_test_operation row
       └─ Operation types: bash_command, file_create, subagent_spawn, web_search

    3. Daily Aggregation (Scheduled)
       ├─ GROUP BY date_utc, environment
       ├─ Calculate AVG/MIN/MAX/SUM of metrics
       └─ UPSERT into stress_test_metrics_daily

    4. Query Results
       ├─ Recent tests via idx_stress_test_run_start_time
       ├─ Failed tests via idx_stress_test_run_failed
       ├─ Trends via stress_test_metrics_daily
       └─ Details via JOIN with operations
