QA-only test asset for T-JOURNEY. Open `journey` on QA Account B. Outer page Tabs publish to the host; inner Tabs select real bodies. `Journey reject` deliberately retains the selected body and increments a visible counter on Overview. Disable the fixture to retire the selected hosted frame, re-enable to recover, then uninstall. No Actions, Resources, external calls, stored data or bundled-plugin membership.

Build the QA browser asset with `node build.mjs`, then stage it with `happier-plugin-build-ui --project-root .`. Copy this fixture and its generated assets to an owned temporary directory without `node_modules`, then pack it with `happier plugins pack <path> --out <archive.tgz>` and install the resulting archive with `happier plugins install <archive.tgz> --machine-id <qa-machine>`. Use Plugin settings on that Machine to select this version for the QA Account; a mutable local-path install does not provide a portable hosted artifact. Both entrypoints intentionally perform no daemon work. Browser compilation maps the public React Native package to react-native-web, as in the external-authoring browser fixture. Generated assets stay ignored.
