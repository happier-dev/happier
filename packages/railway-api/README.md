# Railway API

Public Railway GraphQL transport and project operations shared by Happier plugins. Pass an authenticated request function to `createRailwayGraphqlClient` or `createRailwayProjectOperations`. The Railway Connected Account owned by Machine Railway supplies authorization through Plugin SDK host services.

## Evolving the API

This package is in developer preview. It uses public Plugin SDK entry points and its operations are shared by first-party Railway plugins. External publication requires maintainer approval.
